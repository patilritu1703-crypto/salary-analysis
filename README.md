# Employee Salary Analysis

## Task Description
This project analyzes employee salary data using Python and calculates important salary statistics.

## Objective
To practice numerical data processing and basic calculations using Python.

## Technologies Used
- Python
- Visual Studio Code

## Features
- Stores employee salaries in a list.
- Calculates total salary.
- Calculates average salary.
- Identifies the highest salary.
- Identifies the lowest salary.
- Compares each employee's salary with the average salary.

## Sample Results
- Number of Employees: 8
- Total Salary: ₹2,75,000
- Average Salary: ₹34,375
- Highest Salary: ₹50,000
- Lowest Salary: ₹25,000

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

   `python salary-analysis.py`

## Conclusion
This task demonstrates how Python's built-in functions, including `sum()`, `len()`, `max()`, and `min()`, can be used to analyze employee salary data efficiently.
